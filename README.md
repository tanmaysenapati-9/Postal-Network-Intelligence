# Postal Network Intelligence

This is my Power BI project based on postal office records in India. The main goal was to analyze delivery status and check the quality of geographical coordinates in the dataset.

While building the dashboard, I found it challenging to adjust the map so that the postal office locations could be viewed properly. I also worked on presenting the three coordinate categories — complete, missing, and invalid  in a way that makes the data-quality results easier to understand.

## What I did
- Analyzed delivery and non-delivery records.
- Calculated coordinate completeness.
- Separated records into complete, missing, and invalid coordinate categories.
- Created KPI cards, charts, a summary table, and a map in Power BI.

## Tools Used
- Microsoft Power BI
- DAX

## Results
- Total records: 165,627
- Complete coordinates: 153,388
- Missing coordinates: 12,015
- Invalid coordinates: 224
- Coordinate completeness: 92.61%

## Project File
`Postal_Network_Intelligence.pbix` — contains my Power BI dashboard.

## What I Learned
This project gave me practical experience in data analysis and visualization. I also learned that arranging map visuals and presenting data-quality categories clearly are important parts of making a dashboard useful.
